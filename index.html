Final-year project · IBM SPSS Statistics

Air Pollution in Klang

Which weather conditions were associated with days when the Air Pollution Index (API) exceeded 100?

I combined daily API readings with weather data for 2023–2024 and fitted a binary logistic regression model using 720 daily observations.

Methods and findings

I examined temperature, relative humidity, wind speed, wind direction and rainfall. Wind direction had the largest Wald statistic among the predictors in the fitted model. Temperature, wind speed and rainfall were also statistically significant. Relative humidity was not statistically significant.

The quarter with the highest average API was Q3 2024. The chart shows rounded quarterly averages.
